# Wrap the session

1. Make sure everything is committed and pushed (or the pull request is open at Level 5).
2. Update `docs/PROGRESS.md`: current level, what was done today (bullets), the next 1–3 tasks, open questions for the Owner. If any Level 3 entry test is still ✗, list those items first under "Next" (Part 1 of `docs/AFTER-THE-LAB.md`).
3. Add CHANGELOG lines for anything shipped. If this is at least the second wrap note in `docs/PROGRESS.md`, tick `l3-wrap` in `docs/PASSPORT.md`.
4. Ask the Owner one question: "What one thing would have made today faster?" If it is a repeatable lesson, add it to AGENTS.md §7.
5. Show a 5-line wrap: done · live link · next task · one coach tip for next time · level status.
6. Suggest: "Start a fresh session for the next task and say 'continue my build'. I'll pick up from docs/PROGRESS.md."
